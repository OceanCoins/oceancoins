# Ocean Coin

A small reminder, passed from hand to hand.

Ocean Coin encourages simple acts of environmental stewardship by tracking the journey of physical coins as they travel from person to person around the world.

## Features

- 🌎 Interactive world map
- 🪙 Individually tracked coins
- 📖 Journey timeline
- 🧭 Journey markers and milestones
- ♻️ Cleanup logging
- 📍 Distance traveled

## Development

```bash
npm install
npm run dev
```

- Next.js
